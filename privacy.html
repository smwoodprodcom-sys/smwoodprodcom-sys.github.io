Privacy Notice

Last updated: 6 October 2026.

This notice describes a locally operated Rclone OAuth client used by its owner to access Google Drive. The static website hosting this notice does not accept Google Drive data, OAuth tokens, or passwords.

Data and permissions

The OAuth configuration requests the Google Drive scope https://www.googleapis.com/auth/drive, which grants broad access to the authorizing Google account's Drive. Rclone may process file names, folder paths, sizes, modification times, and file contents when the operator runs commands or local automation. Operations may include reading, creating, updating, moving, renaming, or deleting files, depending on the command used.

How information is handled

  • Rclone sends the API requests needed for the operation to Google. Google processes that information under Google's own terms and privacy notices.
  • OAuth tokens are stored in the local Rclone configuration on the operator's computer. File metadata may be stored in a local search index. File contents may be cached locally when read or written, subject to the local Rclone cache settings.
  • Local agents or software explicitly configured by the operator may access files available through the local Rclone mount. The operator controls that machine and its local access.
  • When such an agent is configured to use an external AI/model/API service, it may send selected file contents or excerpts, filenames or other metadata, prompts, and related context to that provider for the requested task. Tools/orchestrators in the environment may include Codex, DeepSeek clients, Grok/xAI, Anthropic/Claude, Google Gemini, Cline, OpenCode, MCP Commander, and other configured providers. The actual recipient depends on the selected agent and its routing configuration; this is not a claim that every provider receives every file.
  • Each external provider processes information under its own terms, privacy notice, and account settings. This notice does not promise that providers never retain submitted information or use it for model improvement. The operator must check the chosen provider's terms and controls and ensure appropriate authority/consent before sending sensitive or third-party data. Granting Rclone Google Drive access is not, by itself, consent to send Drive content to an AI provider.
  • This website is a static information site; it has no server-side Drive integration and does not receive Drive contents or OAuth tokens. GitHub hosts the static pages and may process ordinary website visitor requests under GitHub's privacy terms.

Sharing and retention

This setup is intended for the account owner or an account holder who independently chooses to authorize and configure their own Rclone use. Authorizing the OAuth client does not publish or share Drive files. Local tokens remain until removed or revoked. Local metadata and cached content remain according to the operator's local index and cache settings, until refreshed, evicted, or deleted.

Choices and revocation

An account holder can revoke the app's Google access in their Google Account security settings under third-party connections. The operator can also stop Rclone and remove its local token, index, and cache. Revoking access does not automatically remove copies already downloaded or cached locally; those must be cleared from the local machine.

Security

Local configuration files contain sensitive OAuth credentials and should be protected by the computer's access controls and disk security. No security method is guaranteed, so credentials should not be published or shared.
